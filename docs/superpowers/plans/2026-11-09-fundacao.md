# Fundação (etapas 1–6) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a fundação medida do recomendador. Ela cobre ambiente, dados verificados, divisões, régua, banco vetorial com busca reprodutível, métricas, linha de base por popularidade e geração híbrida de candidatos. A rede neural fica para o Plano 2.

**Architecture:** Node.js com ES modules. Módulos pequenos por responsabilidade (`src/dados`, `src/features`, `src/banco`, `src/candidatos`, `src/avaliacao`, `src/util`). Cada etapa do roteiro é um script em `scripts/` que combina os módulos e imprime números verificáveis. O Postgres com pgvector roda no Docker. Testes unitários em `node:test` e testes de integração separados, que precisam do Docker.

**Tech Stack:** Node 20 LTS, `pg`, `dotenv`, `adm-zip`, `@tensorflow/tfjs-node` (só o teste de ambiente neste plano), Docker com `pgvector/pgvector` (série 0.8, Postgres 17), `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-07-recomendacao-filmes-design.md` (v3.1, congelada). Quem executa lê a spec e o plano. Este plano cita as seções da spec por número.

## Global Constraints

- **Raiz do projeto:** `C:\dev\recomendacao-filmes`. Todos os caminhos abaixo são relativos a ela. Nada é criado dentro do OneDrive.
- **Repositório:** o `.gitignore` é criado **antes** do `git init`. Ficam fora do git: `data/`, `*.zip`, `.env`, `node_modules/`, `modelos/`, `artefatos/`, `*.log`. A pasta `resultados/` é versionada.
- **Dados:** o MovieLens nunca vai para o repositório nem para os testes. Os testes usam apenas dados sintéticos criados no próprio teste.
- **Leitura:** o `u.item` é lido em latin-1 (`fs.readFileSync(caminho, 'latin1')`).
- **"Gostou":** nota ≥ 4. Relevância é binária.
- **Validação:** usuários 463–943, com 40% das notas de cada um escondidas e semente **42**. O teste são os usuários do `u1.test` (1–462).
- **Regra do teste único:** nenhum script deste plano lê o `u1.test` para métricas. Só a divisão o carrega.
- **Vetor de busca:** 23 dimensões = gênero 19 (normalizado, × 0,6) + época 3 faixas (normalizado, × 0,2) + popularidade 1 (log(1+n), mín/máx, cortada em [0, 1], × 0,2).
- **Determinismo:**
  - todo sorteio usa o gerador com semente de `src/util/aleatorio.js`;
  - popularidade é ordenada por (contagem decrescente, id crescente);
  - distâncias são ordenadas por (distância, id crescente).
- **Banco:**
  - porta do host **5433**, volume nomeado, tag exata da imagem;
  - busca feita numa transação com `set_config('hnsw.ef_search', …, true)` e `SET LOCAL hnsw.iterative_scan = strict_order`;
  - N ≤ 100;
  - desempate feito no código, nunca no SQL.
- **Falhar alto:** dimensão divergente, menos de N linhas, hash de régua divergente, régua ausente, banco fora do ar e NaN geram sempre um erro com uma mensagem que diz o que fazer.
- **Idioma:** nomes de funções, arquivos e mensagens em português (camelCase), seguindo a spec.

### Task 4: Gerador com semente e divisões

**Files:**
- Create: `src/util/aleatorio.js`, `src/dados/divisoes.js`, `tests/unidade/divisoes.test.js`

**Interfaces:**
- Produces:
  - `criarAleatorio(semente: number) → () => number`, que devolve um número em [0, 1);
  - `embaralhar(array, aleatorio) → array` (cópia; Fisher-Yates);
  - `criarDivisoes({ base, teste }, { semente = 42, usuariosValidacao = [463, 943], fracao = 0.4 }) → { treinoExp, validacao, treinoFinal, teste }`. Cada valor é um array de avaliações. `treinoFinal` é igual a `base`.

O gerador é fixo (mulberry32), porque o resultado precisa ser idêntico em qualquer máquina:

```js
export function criarAleatorio(semente) {
  let a = semente >>> 0;
  return () => {
    a = (a + 0x6D2B79F5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

**Regra da divisão:** para cada usuário de validação, ordenar as avaliações dele por id do filme, embaralhar com um gerador criado com `semente + idUsuario` e esconder as primeiras `Math.round(fracao × n)`.
